## PAGE 1: Words for rooms and items
To write about the house, you need to be able to spell these words. Copy each one slowly, with the little word le or la in front.

la maison       the house
la chambre      the bedroom
le salon        the living room
la cuisine      the kitchen
la salle de bain  the bathroom
la porte        the door
la fenêtre      the window
le lit          the bed
la table        the table
la chaise       the chair

### Spelling hints
Chambre has the letters m-b-r, not m-r. Fenêtre has an accent circonflexe on the first ê and the ending tre. Salle de bain has three separate words: salle, de, bain.

### Try it
Cover the list. Write the French words for house, bed, door and window from memory. Then check your spelling and correct any mistakes.

## PAGE 2: Matching pictures and words
Matching activities help you link a picture to its word. Imagine a picture and choose the right French word.

1. A picture of a bed        ______
2. A picture of a door       ______
3. A picture of a kitchen    ______
4. A picture of a chair      ______

Word bank: la cuisine, la chaise, la porte, le lit

Answers: 1. le lit  2. la porte  3. la cuisine  4. la chaise

### A second matching task
Match each item to the room where you usually find it.
le lit           la chambre
le canapé        le salon
le frigo         la cuisine
la douche        la salle de bain

La douche means the shower (la DOOSH).

### Try it
Draw a simple house with four rooms in your exercise book. Write the French name of each room. Add two items inside each room and label them in French.

## PAGE 3: Writing short phrases
A phrase is a small group of words. To write a phrase about an item at home, use le or la and the noun. To say what something is, start with C'est.

C'est une table.       It is a table.
C'est un lit.          It is a bed.
C'est une chaise.      It is a chair.
C'est un canapé.       It is a sofa.

Un is used before a masculine noun. Une is used before a feminine noun. Both mean a or an.

### Say what is in a room
Dans la cuisine, il y a un frigo.
Dans le salon, il y a un canapé.
Dans la chambre, il y a un lit.

Notice how each phrase names a room, then adds Il y a and an item.

### Try it
Write two phrases to describe your own house. Use Il y a and a room name. For example: Dans la chambre, il y a un lit.

## PAGE 4: Writing where things are
You can also write sentences to say where things are. Use the prepositions from earlier lessons.

Le livre est sur la table.
Le sac est sous la chaise.
Le chat est dans la maison.

### Sentence order
A correct French sentence has this order:
1. The thing (Le livre)
2. est
3. The preposition (sur)
4. The place (la table)

### Put the words in order
1. table / est / sur / le livre / la
   Answer: Le livre est sur la table.
2. chaise / le sac / sous / la / est
   Answer: Le sac est sous la chaise.

### Write instructions
Instructions tell people where to put things. Use Mets for a friend.
Mets le sac sur la chaise.
Mets le livre dans la chambre.

### Try it
Write three instructions using Mets and a different preposition each time.

## PAGE 5: Check, correct and summarise
Good writers always check their work. Read your sentences aloud, look at each word, and check spelling, accents and capital letters.

### Editing checklist
1. Does every sentence start with a capital letter?
2. Does every sentence end with a full stop?
3. Are the words le, la, un and une correct?
4. Are the accents right, for example in fenêtre?
5. Can someone else read my handwriting?

### Common mistakes
• Writing la lit. Lit is masculine: le lit.
• Writing la salle du bain. It is la salle de bain.
• Leaving out the accent in fenêtre.
• Starting a sentence with a small letter.

### Final task
Write four sentences about a room in your house. Use Il y a or est. Give your writing to a friend to read aloud to check that it is clear.

### Summary
You can write the names of rooms and items, match them to pictures, write short phrases with C'est, Il y a and est, and write simple instructions with Mets. Writing carefully makes it easy for others to understand you.

## QUIZ
1. Which is the correct spelling of window?
   A) fenetre
   B) fenêtre
   C) fenêter
   D) fênetre
   Answer: B
   Why: The word is fenêtre, with the circumflex on the second e.
2. Which word goes with un?
   A) table
   B) chaise
   C) lit
   D) porte
   Answer: C
   Why: Lit is masculine, so we say un lit.
3. Which sentence is correct?
   A) La livre est sur la table.
   B) Le livre est sur la table.
   C) Le livre sur est la table.
   D) Livre le est sur table.
   Answer: B
   Why: The order is thing, est, preposition, place.
4. Where do you usually find le frigo?
   A) la chambre
   B) la cuisine
   C) le salon
   D) la porte
   Answer: B
   Why: A fridge is in la cuisine, the kitchen.
5. What does Mets le sac sur la chaise mean?
   A) Put the bag on the chair
   B) Take the bag from the chair
   C) Where is the bag?
   D) The bag is on the chair
   Answer: A
   Why: Mets is an instruction meaning put.
6. Write in French: It is a table. (2 marks)
   Answer: C'est une table.
   Why: 1 mark for C'est and 1 mark for une table.
7. Write in French: In the kitchen, there is a fridge. (3 marks)
   Answer: Dans la cuisine, il y a un frigo.
   Why: 1 mark for dans la cuisine, 1 mark for il y a and 1 mark for un frigo.
8. Put these words in order: sous / est / le chat / la chaise (2 marks)
   Answer: Le chat est sous la chaise.
   Why: 1 mark for the correct order and 1 mark for a capital letter and full stop.
9. Write two instructions with Mets to tell a friend where to put a book and a bag. (4 marks)
   Answer: Mets le livre sur la table. Mets le sac dans la chambre.
   Why: 2 marks for each correct instruction.
